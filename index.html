Get Session ID (AUTH_STATE)

To get the session ID (base64 auth state):

  1. Run the v1 bot locally: npm run start:v1 and scan QR to login.
  2. Then run: npm run export-auth — this prints a base64 string.
  3. Copy that string and paste it into your hosting panel's env var named AUTH_STATE.

You can also download export-auth.js and run it on the host where v1_auth.json is present.

Security: keep this value secret.

Notes

  • Replace the GitHub URL above with your repository URL after you create the repo.
  • Run npm run package to generate project.zip locally using Node.
  • Scan the QR code when the bot starts to login (Baileys auth will be saved in auth_info).
