Bot Menu & Commands

Commands available in the bot scaffold — copy/paste into WhatsApp:

General

  • !menu — show menu (plays a short audio preview)
  • !toggle <feature> on|off — toggle features

Group

  • !group add <phone> — add a participant (bot must be admin)
  • !group promote <phone> — promote to admin (group only)
  • !group demote <phone> — demote from admin (group only)

Games

  • !ttt — start tic-tac-toe
  • !move <1-9> — make a move

Bugs

  • !bug report <text> — report a bug
  • !bug list — list reported bugs
  • !bug close <id> — close bug (owner only)

UX notes

  • The menu command plays a short TTS audio, then prints the menu text for accessibility.
  • Owner-only commands will return a clear warning: "This command is for the owner only."
  • Group-only commands will return: "Group commands must be run from a group chat."

To connect the bot to a GitHub repo: create a repo, push these files, then update the GitHub link on the project homepage (index.html).
