Bot Menu & Commands

Commands available in the bot scaffold:

  • !menu or /menu — show the bot menu and enabled features.
  • !toggle <feature> on|off — enable or disable runtime feature toggles (autoread, autoreact, autoviewstatus).
  • !group add <phone> — request to add a participant to a group (placeholder: requires admin privileges and contextual handling).

Features explained

  • autoread: Marks incoming messages as read automatically.
  • autoreact: Sends a quick emoji reaction to incoming messages.
  • autoviewstatus: Attempts presence/subscribe behavior for viewing status updates.

To connect the bot to a GitHub repo: create a repo, push these files, then update the GitHub link on the project homepage (index.html).
